# Documentation

| Path | Contents |
| :--- | :--- |
| `experiments/` | One file per fix: hypothesis, change, runs, results, decision |
| `harness/` | The benchmark harness: Wine setup on macOS (`wine.md`), scenario, run rules and run validity (`bench.md`) |
| `ace-notes.md` | Notes for the ACE team, with evidence and the patches in this mod |
| `backlog.md` | Ranked list of measured and code-confirmed items, with status |
| `atlas/findings.md` | Static review of the base game, DLC and ACE Lua code (verified and unverified candidates) |
| `atlas/profiles-2026-10-28.md` | Lua CPU profiles of the benchmark's measured game day, vanilla and ACE |
| `atlas/load-save-ui.md` | Where launch, save-load, save and UI boot time goes, vanilla and ACE |
| `publication-guidelines.md` | How this project writes about the game, ACE and its own numbers |

Run directory names (`runs/<timestamp>-<name>`) and commit hashes in these documents refer to the development repository; run output is not published.
